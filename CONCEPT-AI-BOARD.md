# Вкладка «ИИ» — доска идей и живой агент (14.09.2026)

Задание себе. Цель владельца: человек заходит во вкладку, пишет промт, идёт быстрое
голосование, победитель уходит агенту, результат появляется — и так по кругу,
чтобы люди могли сидеть и коллективно программировать монету. Без раз-в-неделю.

## Принципы

1. **Одна вкладка — одно действие.** На экране только то, что можно сделать или
   увидеть: написать идею, проголосовать, посмотреть результат. Никаких
   манифестов, циклов недели, списков «агент никогда не будет» — это в подсказку.
2. **Без раундов вообще.** Раунды с таймерами — это очередь у кассы. Вместо них
   **живая доска**: идеи копятся, голоса считаются сразу, и каждый раз, когда
   агент свободен, он забирает **верхнюю** идею. Твой голос можно переставить в
   любой момент — вес уходит за тобой. Это быстрее «раз в 5 минут»: как только
   идея наверху и агент свободен — она в работе.
3. **Ритм задаёт агент, не календарь.** Он просыпается каждые 5 минут (чаще
   GitHub не умеет) и строит не больше одной страницы за раз. Пока строит —
   доска видит «строит: …», следующая идея ждёт.
4. **Деньги честно.** Сборка стоит денег (модель). Первые **3 сборки у монеты —
   за счёт hood**, дальше агент строит только на бюджет монеты (10% комиссии
   с ИИ-монет копятся в AgentTreasury). На доске видно: «бюджет ≈ N сборок».
   Хочешь, чтобы агент строил чаще — торгуй монетой.
5. **Вес голоса — доля в монете.** Как было. Предлагать — от 0.1% выпуска, чтобы
   доску не заливали. Один кошелёк — один голос (переставляемый).
6. **Всё проверяемо.** Идеи и голоса подписаны кошельком, подделка не считается
   (как в weekly-мастерской). Что построено — в builds.json репозитория, его
   не подделать без доступа к сайту. Стоимость каждой сборки — там же.

## Экран (desktop: две колонки, mobile: стопка)

```
[монета ▾ $DOGE]   агент: свободен · заглянет через 2:40 · бюджет: 3 бесплатные сборки
──────────────────────────────────────────────────────────────────────────
ДОСКА ИДЕЙ                                  │ ПОСТРОЕНО
[ Что построить? ______________ ] [Предложить] │ ▸ Игра: лук и мишени   $0.09 · 2ч назад
                                             │   Открыть ↗   модель Claude Fable 5.1
① Сделай таймер обратного отсчёта…  62% ████│ ▸ …
   0xd3d1…6255 · 4 мин · [Голосовать]        │
② Страница-мем с генератором…       31% ██  │ ФАКТЫ (одна строка внизу)
③ …                                  7% █   │ агент не трогает деньги и не даёт советов…
```

- Верхняя идея подсвечена: «следующая в работу».
- Идею, которую агент уже взял, доска убирает (по builds.json / маркеру `building`).
- Кошелёк не подключён — доску видно, кнопки ведут в «Подключить».
- Обновление живое: поток RTDB (EventSource), запасной опрос раз в 10 с.

## Данные (Firebase RTDB, открытая база — подписи решают)

```
workshop/board/<token>/proposals/<pid> = { text, by, at, sig }   // sig автора
workshop/board/<token>/votes/<addr>    = { pid, at, sig }        // sig голосующего; pid "" = снял голос
workshop/board/<token>/building        = { pid, at }             // маркер агента, только для статуса
```
Подписываемые строки:
```
hood board proposal\ntoken: <token>\npid: <pid>\ntext: <text>
hood board vote\ntoken: <token>\nproposal: <pid>
```
Вес = balanceOf в момент подсчёта (v1, как в weekly). Учтённая идея = pid есть в
builds.json (агент коммитит его вместе со страницей).

## Агент (scripts/agent-run.mjs, cron */5)

1. Все монеты обеих фабрик; при живом сплиттере — только с `aiOf = true`.
2. Для каждой: доска → подписанные голоса → веса → верхняя идея с весом > 0,
   которой нет в builds.json.
3. Гейт денег: сборок у монеты < 3 — бесплатно; иначе бюджет AgentTreasury
   (ETH или валюта монеты, в долларах по курсу) ≥ оценка стоимости модели.
4. Одна сборка за запуск. Выбор монеты — та, чью доску дольше всех не
   обслуживали (round-robin), чтобы одна активная монета не забирала агента.
5. Пишет `building` маркер → строит → коммитит страницу + builds.json (с `pid`)
   в staging → просит пересборку. Результат виден во вкладке сразу (читаем
   builds.json со staging-сайта).

## Что убираем с экрана (код остаётся за флагами)

Недельный круг, «Агентов ещё нет», «Очередь задач» (её заменяет доска),
«Агент никогда не будет» (в подсказку «?»), журнал с ручной формой оператора
(результаты берутся из builds.json). Weekly-мастерская остаётся в коде
(components/Workshop.jsx, lib/workshop.js) — вдруг понадобится.

## Не делаем в v1 (честно)

Снимок балансов на момент голосования (защита от займа), защита от удаления
чужих голосов в открытой базе (нужен бэкенд или голоса в цепи), on-chain
списание бюджета агентом из CI (нужен ключ оператора в секретах — отдельный
кошелёк, не главный).
