# Проверка безопасности перед запуском — 15.09.2026

Что проверялось: контракты (фабрики V2 и за валюту, пулы, миграторы, зап,
DividendToken, сплиттеры, казна арены, FeeClaimer, старые казны), живые
контракты мейннета (пробы чужим адресом через eth_call), сайт (админка, XSS,
транзакции, approve, слиппедж, метаданные, localStorage), база Firebase
(правила + живые пробы записи), воркер, GitHub Actions, зависимости,
секреты в репозитории и истории git, краш-тест страниц (desktop + телефон,
мусорные маршруты, без RPC).

Метод: два независимых ревью кода, фаззинг математики кривой и дивидендов,
воспроизведение атак на **настоящем** Uniswap V3 (артефакты v3-core/periphery),
живые пробы мейннета и базы.

## Итог

Кражи денег с цепи нет: чужой адрес не может вызвать функции владельца и
вывести ETH/акции из пулов, казны, сплиттера, запа, мигратора. Кривая и
дивиденды сходятся. Админка без кошелька владельца ничего не даёт.

Главная найденная проблема — не кража, а **заморозка при градации**
(исправлена в контрактах для перезапуска). Остальное — средние и мелкие
вещи на сайте и в базе, исправлены на staging; часть требует действий
владельца (ниже).

## База Firebase (`firebase/database.rules.json`, опубликовать в консоли)

Было: любые лишние поля без ограничения размера (счёт за трафик, обвал
страниц), удаление/перезапись чужого присутствия и активности, мусор под
чужими адресами профилей с ключами «из будущего», открытый `workshop`.
Стало: у каждой ветки перечислены допустимые поля, лишние отклоняются;
размеры и типы; `chats` — комната только адрес, ключ только push-id,
индекс по `ts`; `presence` — удалять можно только записи старше часа;
`activity` — свои отметки только 1→2, удалять только корзины старше 31 дня;
`bans` — подписанный документ; `workshop` — только чтение.

Мусор от проб (безвредный, удалить в консоли при желании):
`chats/__audit_room__`, `profiles/0x000…0001`, `revenue_waitlist/__audit__*`.

## Что делает владелец

1. Опубликовать правила базы (Firebase → Realtime Database → Rules →
   вставить `firebase/database.rules.json` → Publish), потом сказать — проверю
   живыми пробами. Старые правила сохранить на случай отката.
2. Cloudflare → Rules → Transform Rules → Modify Response Header:
   `X-Frame-Options: DENY`, `X-Content-Type-Options: nosniff`,
   `Referrer-Policy: strict-origin-when-cross-origin`; SSL/TLS → Edge
   Certificates → HSTS включить; «Always Use HTTPS».
3. 2FA на GitHub, Cloudflare, Firebase/Google, Alchemy, Goldsky. Лимиты трат:
   Alchemy, Firebase (Budget alert), OpenRouter.
4. Ключ владельца лежит в `scripts/deploy-config.json` открытым текстом —
   после перезапуска передать владение фабриками на аппаратный кошелёк
   (`transferOwnership` → `acceptOwnership` с него); деплойный ключ держать
   только с газом. `githubToken` — заменить на fine-grained с правами
   только на Actions.
5. Перезапуск делать на исправленных контрактах (этот коммит), сразу
   `initConfig` после деплоя фабрик (иначе запуск монет закрыт).
