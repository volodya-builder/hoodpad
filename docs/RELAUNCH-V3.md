# Перезапуск V3 — антиснайп + казны с покупкой на Uniswap (18.09.2026)

Что меняется и зачем — коротко:

- **Стартовый налог против снайперов**, как у Pons: первые 5 секунд после
  запуска монеты покупка облагается налогом 99% → 25% → 3% → 0,4% → 0,05% → 0.
  Только покупки. Создатель освобождён (его покупка в той же транзакции —
  без налога), при запуске можно освободить до 32 адресов. Налог идёт в общий
  котёл комиссий и делится 70/10/10/10. Живёт в пуле → новые фабрики.
- **Казна V3 покупает градуировавшие монеты на Uniswap V3** (`buybackDex`).
  У V2 после градации выкупы останавливались.
- **Выкуп hood — раз в час** (бот `buyback.yml` с эстафетой).
- **Новые кошельки**: владелец `0x53eB…4F736`, команда `0x0462…87b3`,
  бот арены `0x4fC0…8B63` (оператор казн), бот дивидендов `0xc649…9b9C`.
- Таймлок не нужен: фабрики свежие, `initConfig` сразу.

Контракты: `contracts/OpeningTax.sol`, `BondingCurvePoolV3.sol`,
`BondingCurvePoolQuoteV3.sol`, `LaunchpadFactoryV3.sol`,
`LaunchpadFactoryQuoteV3.sol`, `ArenaTreasuryV3.sol` (+ старые
`UniswapV3Migrator`, `UniswapV3MigratorQuote`, `CurveZap`, `FeeSplitterV6`,
`LaunchToken`, `DividendToken` без изменений). Тесты: `test/v3.test.mjs`
(11, в т.ч. против настоящего Uniswap V3), `test/hardening-v3.test.mjs` (11).

## Порядок (делает владелец)

### 0. Перед деплоем
1. Старую монету HOOD (0x9eFD…) распродать обратно в кривую с тех кошельков,
   где она лежит, пока кривая открыта — вернётся ~99% ETH. После переключения
   сайта старые монеты с сайта пропадут (как в прошлые перезапуски).
2. Пополнить `hood · Владелец` (0x53eB…) на **0.02 ETH** (деплой стоит
   ~0.004 ETH + акции `allow-stocks --send` ~0.005 ETH + запас).
3. В `scripts/deploy-config.json` положить в `privateKey` ключ кошелька
   `hood · Владелец` (MetaMask → три точки у аккаунта → «Сведения об
   аккаунте» → «Показать закрытый ключ»). Ключ никому не показывать и в чат
   не вставлять. После деплоя — стереть из файла.

### 1. Компиляция и сухой прогон
```
node scripts/compile.js
node scripts/relaunch-v4.js
```
Сухой прогон ничего не отправляет: проверяет ключ (должен быть от
0x53eB…, иначе откажется), баланс, маршруты запа, считает газ. В конце —
«Всё готово к боевому запуску».

### 2. Деплой
```
node scripts/relaunch-v4.js --deploy
```
11 шагов с контрольными точками (`scripts/relaunch-v4-progress.json`); если
оборвётся — повторить ту же команду, продолжит с места обрыва. В конце —
сверка с цепью и `scripts/relaunch-v4-output.json` с адресами.

### 3. Акции и крипта (белый список валют + маршруты запа)
```
QUOTE_FACTORY=<quoteFactory из output> ZAP=<zap из output> node scripts/allow-stocks.js --send
```
(в PowerShell: `$env:QUOTE_FACTORY="0x…"; $env:ZAP="0x…"; node scripts/allow-stocks.js --send`)

### 4. Прислать адреса в чат
Содержимое `scripts/relaunch-v4-output.json`. Дальше Claude одним коммитом
переключает сайт, ботов, сабграф и документацию (`scripts/switch-addresses.js`).

### 5. GitHub → Settings → Secrets and variables → Actions
- Secrets: `ARENA_PRIVATE_KEY` = ключ `hood · Бот арены` (0x4fC0…),
  `TREASURER_PRIVATE_KEY` = ключ `hood · Бот дивидендов` (0xc649…).
- Variables: `ARENA_TREASURY`, `BUYBACK_TREASURY` — из output;
  `HOOD_TOKEN` — адрес новой монеты hood после её создания.
- Газ ботам: 0x4fC0… ≈ 0.02 ETH, 0xc649… ≈ 0.05 ETH.

### 6. Сабграф
После переключения (шаг 4) — задеплоить новую версию `hood-mainnet/6.0.0`
на Goldsky из папки `subgraph/` (адреса и startBlock уже подставлены).
Сайт сам выберет новую версию, когда она синхронизируется.

### 7. Верификация исходников
```
node scripts/verify-v4.js --dump
```
Файлы для Blockscout — в `scripts/verify-out/`; дальше как в прошлый раз
(через браузер, один контракт в ~25 минут из-за лимита обозревателя).

### 8. Монета hood заново
Создать на сайте с кошелька `hood · Команда 10%` (создатель получает 70%
комиссий монеты) — как раньше. В «Дополнительно» можно вписать адреса,
освобождённые от стартового налога (свои торговые кошельки). Адрес монеты —
в переменную `HOOD_TOKEN` и в чат (Docs).

### 9. Запустить эстафеты ботов
Actions → «hood dividends» → Run workflow (run); «Арена платит подиуму» →
Run workflow; «hood buyback» → Run workflow (dry не ставить). Дальше они
ходят сами.

### 10. GMGN
Прислать в чат поддержки обновлённые адреса фабрик (текст подготовит Claude).
